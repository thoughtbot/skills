# design

Skills for product design work. Skills that are scoped to the design domain,
such as design process, critique, and collaboration, live here.

## Installation

Add the marketplace and install the plugin in Claude Code:

```
/plugin marketplace add thoughtbot/skills
/plugin install design@skills
```

## Skills

Skills are added under this plugin's `skills/` directory as they land. See
the repository's [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to add one.
